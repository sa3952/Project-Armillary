信任與隱私重點

僅限受邀測試；不建立 account database。出生日期時間、時區與精確座標經 HTTPS 傳至 Infomaniak 瑞士 VPS，只用於這次 chart／dossier 計算；application 不持久化 request／response、不加入 analytics 或第三方 telemetry，且 /api/chart 不產生 application access log。

NGINX access log 關閉且不把原始IP傳給application；provider與Internet網路仍會處理 連線metadata。RAM、clipboard與下載檔不能安全抹除。請只輸入你有權使用的資料； 本工具不是醫療、法律、財務或其他專業建議。完整限制見下方。

目前本機版的資料流與限制

出生資料只在目前頁面的 browser memory、同源 POST /api/chart request、 本機計算 process 與 response 中處理；目前路徑不使用出生資料資料庫、request cache 或 background queue。canonical launcher 關閉 Uvicorn access log，application event 只接受 固定欄位。

App 不自動使用 browser storage API 保存出生資料。清除本頁敏感資料會清空 App 仍控制的 表單、結果、錯誤、匯出狀態與暫存 URL；清除無法撤回已寫入剪貼簿或已完成的下載，也不代表 RAM、browser history、crash restore 或作業系統副本已安全抹除。

本機頁面不證明未來host的proxy、CDN、hosting、telemetry、jurisdiction或E2EE share邊界； Private Alpha的已選政策與待真實host驗證事項請見其專用說明。既有Claude coverage queue 已關閉，但這不是security approved、安全或法規認證。

Private Alpha 的資料流、保留與限制

每位受邀者使用獨立、可撤銷、無識別性的HTTP Basic credential；伺服器只保存bcrypt hash， 不建立account database、自助註冊、email或忘記密碼系統。出生資料會存在目前頁面的 browser memory、同源 POST /api/chart request、application process memory與 response；application不把chart request／response放入database、request cache、 background queue或檔案。

服務部署於Infomaniak瑞士VPS；其一般條款對客戶傳送資料承諾使用自有瑞士資料中心。 Host NGINX關閉access log，且不把原始IP或forwarded-IP headers交給application； /api/chart跳過application access event。服務不使用analytics、Sentry、 APM或遠端log forwarding。DNS、ACME、Internet transit與provider仍可能處理IP及連線metadata， 所以本服務不宣稱「所有metadata都只在瑞士」或「零第三方接觸」。

部署政策停用host及container swap、core dump、自動backup／snapshot與出生資料Volume； journald最多保留7日且50 MiB，只接收封閉營運欄位。這些控制必須在每台真實host以verifier及 privacy canary重驗。清除本頁敏感資料可清空App仍控制的表單、結果、錯誤、匯出狀態與暫存URL； 無法安全抹除RAM，也無法撤回clipboard、browser download、extension、provider incident copy 或使用者建立的外部副本。
